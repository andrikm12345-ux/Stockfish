# Combo Engine Chess Bot

Бот для игры на Lichess и Chess.com. Два движка в одном: **Maia** играет как человек, **Stockfish** страхует от зевков. Снаружи — живой игрок 1850–1900.

---

## Режимы работы

| Режим | Когда | Как выбирает ходы |
|---|---|---|
| **Combo** (рекомендуется) | `lc0.exe` + `maia-1900.pb.gz` есть | Maia делает ходы, SF ловит зевки |
| **Чистый SF** (фолбэк) | Файлы Maia не найдены | Только Stockfish, всё как раньше |

При старте бот сам определяет режим и пишет об этом в консоль.

## Быстрый старт

### Шаг 1 — Скачай файлы бота

```
bot/
  bot.js            ← главный файл
  stockfish.exe     ← Stockfish движок
  lc0.exe           ← lc0 движок (для Maia)
  maia-1900.pb.gz   ← нейросеть Maia
  package.json
```

**Stockfish:** положи `stockfish.exe` в папку `bot/`

**lc0:** скачай на `lczero.org/play/download` → версия **Windows CPU** → распакуй, возьми только `lc0.exe`

**Maia сеть:** скачай `maia-1900.pb.gz` на `github.com/CSSLab/maia-chess/releases`

### Шаг 2 — Установи зависимости (один раз)

```bash
npm install
npx playwright install chromium
```

### Шаг 3 — Запускай

```bash
node bot.js
```

При запуске увидишь:
```
Maia (lc0) готова — основной движок
Engine ready (Stockfish native)
```

Если `lc0.exe` или `maia-1900.pb.gz` не найдены — бот напишет об этом и продолжит работу на чистом Stockfish.

## Команды во время игры

Вводишь прямо в консоль пока бот работает:

| Команда | Что делает |
|---|---|
| `d 8` | Установить глубину SF вручную (авто отключается) |
| `s 10` | Установить скилл SF 0–20 (влияет только в режиме чистого SF) |
| `a` | Включить авто-глубину обратно |
| `i 20` | Установить инъекцию неточностей вручную (0–100%) |
| `i a` | Вернуть авто-инъекцию (пуля=22%, блиц=24–28%, рапид=20%) |
| `p` | Пауза / продолжить |
| `r` | Рестарт — если бот завис и не ходит |
| `g ссылка` | Перейти на конкретную партию |
| `n` | **Тупой режим** — d1 s1 (только SF режим) |
| `b` | **Вернуть** настройки до `n` |

## Настройки

### Глубина (depth)

В Combo режиме SF использует глубину для проверки хода Maia и для расчёта премувов.

По умолчанию бот **сам выбирает глубину** под контроль времени:

| Режим | Время | Глубина SF |
|---|---|---|
| Пуля | < 3 мин | 5 |
| Блиц | 3–10 мин | 8 |
| Рапид | 10+ мин | 12 |

### Скилл (skill) — только в режиме чистого Stockfish

В Combo режиме скилл не влияет на основные ходы — Maia сама определяет качество игры (~1850–1900 ELO). Скилл применяется только когда SF перехватывает зевок Maia.

В режиме чистого SF:

| Скилл | Примерный уровень |
|---|---|
| `s 6–8` | Новичок, частые зевки |
| `s 10–12` | Средний игрок |
| `s 15` | Сильный любитель |
| `s 17` | ~2100–2200, рекомендуется |
| `s 20` | Почти идеально — палевно |

## Как работает Combo режим

### Выбор хода

```
Maia (1–15 нод, ~5–50мс)  →  предлагает ход
                                     ↓
               SF (depth 3–8) + SEE проверяют: зевок?
                                     ↓
    Зевка нет → играем ход Maia
    Зевок есть → SF подставляет свой ход
```

**Критерии зевка** (хотя бы одно):
- SEE ≥ 450 cp — фигура физически вешается под взятие
- SEE ≥ 250 cp И оценка падает на 60+ cp — мягкий материальный проигрыш
- Оценка падает на 350+ cp — тактическая катастрофа без очевидного взятия

SEE (Static Exchange Evaluation) работает без дополнительных вызовов движка — мгновенно.

В логе:
```
Ход 12 | Думаю...   [debug] maia=e4d5 sf=f3e5 before=45 after=-12 drop=33 SEE=0 depth=8
[maia d8] e4→d5 (80мс думал, 2800мс пауза, 280с)

Ход 18 | Думаю...   [debug] maia=g4h3 sf=d1d4 before=20 after=480 drop=500 SEE=330 depth=8
  [override] Maia вешает материал SEE=330 drop=500 → SF d1→d4
[maia→SF d8] d1→d4 (190мс думал, 3200мс пауза, 255с)
```

`[maia d8]` — Maia сыграла, SF одобрил
`[maia→SF d8]` — SF перехватил зевок Maia

### Ноды Maia по режиму

| Режим | Ноды | Скорость |
|---|---|---|
| Пуля | 1 | ~1–5мс |
| Блиц | 5 | ~5–20мс |
| Рапид | 15 | ~15–50мс |

Больше нод = чуть сильнее и чуть медленнее. В пуле намеренно минимум — там время дороже точности.

### Что Maia даёт

- Человеческие паттерны в выборе ходов — обучена на реальных партиях игроков ~1900
- Естественные ошибки и субоптимальные ходы без искусственных настроек
- Низкий % совпадений с топ-1 линией SF (~50–55% вместо 70% у чистого SF)
- Выглядит как живой игрок 1850–1900

## Инъекции точности

Поверх Maia/SF бот дополнительно «вкидывает» неточные ходы чтобы держать живую точность в диапазоне **70–88%** — как у реальных игроков 1850–1900.

### Как считается точность

По формуле Lichess: изменение вероятности выигрыша в процентах, переведённое в шкалу 0–100. Бот отслеживает точность каждого своего хода (`[live]` в консоли).

### Процент инъекций по режиму

| Режим | Авто % | Описание |
|---|---|---|
| Пуля | 22% | В пуле люди ошибаются заметно — высокая инъекция |
| Блиц (≤ 4.5 мин) | 28% | Короткий блиц самый нервный |
| Блиц (> 4.5 мин) | 24% | Стандартный блиц |
| Рапид | 20% | В рапиде тоже ошибаются, особенно в миттельшпиле |

Установить вручную: `i 30` (30%) или вернуть авто: `i a`

### Как применяется инъекция

Бот берёт топ-3 хода SF и выбирает похуже — **только если**:

1. Нет цейтнота (при < 5–8с на часах инъекции отключаются)
2. Не было инъекции последние 4 хода (кулдаун — не делаем ошибки подряд)
3. Maia не сыграла уже плохой ход (< 80% точности — не добавляем поверх)
4. Это не sf-override (SF уже исправил зевок — не добавляем вторую ошибку)
5. SEE < 450 cp — инъекция не должна вешать фигуру

| Вариант | Условие | Шанс |
|---|---|---|
| m3 (третий по силе) | разница с лучшим < 500 cp | 25% от инжект-шанса |
| m2 (второй по силе) | разница с лучшим < 300 cp | если m3 не подошёл |

### Адаптивный множитель

`liveAdjust` автоматически меняет интенсивность инъекций чтобы точность держалась в цели текущей партии:

| Живая точность | Действие |
|---|---|
| > цель+10% | `liveAdjust` ×1.12 — резкое усиление инъекций |
| > цель+5% | `liveAdjust` ×1.06 — сильное усиление |
| > цель | `liveAdjust` ×1.03 — лёгкое усиление |
| < цель−12% | `liveAdjust` ×0.80 — резкое ослабление |
| < цель−8% | `liveAdjust` ×0.92 — ослабление |
| в диапазоне | медленно возвращается к ×1.0 (цель достигнута) |

Каждые 5 ходов (или когда ход < 75%) в консоли:
```
  [live] точность≈78% | adj=×1.05 | ходов=20
```

### В режиме чистого SF

Серии ошибок (`⚡`) и suboptimal работают как обычно. Инъекции через m2/m3 применяются так же.

## Анти-Irwin защита

Irwin — ML-античит Lichess. Он анализирует не только точность, но и **паттерны поведения**. Бот реализует 4 защиты:

### 1. Межпартийная вариация цели

Каждая партия стартует с **случайной целью точности** в диапазоне 68–84%:

```
gameAccuracyTarget = 68 + random(17)   // например: 71%, 80%, 76%...
```

Irwin сравнивает точность между партиями. Если точность всегда ~77% — это подозрительно. С вариацией одна партия 71%, следующая 82% — как у живого игрока.

### 2. Инъекции в критические моменты

В выигрышных позициях (оценка > 200cp) **7% шанс** сделать неточный ход, даже если бот «не должен был» ошибаться.

Irwin специально смотрит на точность в позициях где m1 ≫ m2 (>200cp разница). Настоящий игрок 1900 находит лучший ход только в 40–60% таких позиций. Без этой защиты бот всегда находит — красный флаг.

### 3. Задержка ∝ сложность позиции

В позициях с **> 32 легальными ходами** (сложный миттельшпиль) задержка умножается на ×1.2–1.4 (при наличии запаса времени > 8с).

Irwin коррелирует время на ход со сложностью позиции по базе данных реальных игр. Слишком равномерное время — аномалия.

### 4. Плановый промах за партию

В 30% партий бот делает **один большой промах** (m3, потеря 300–600cp) после хода 6, с шансом ~5% за ход.

Irwin смотрит на распределение потерь centipawn loss. Нормальное распределение ~1900 включает редкие крупные промахи. Биномиальное распределение (всегда хорошо или всегда одинаково плохо) — аномалия.

SEE-фильтр гарантирует что промах не вешает фигуру полностью (< 500cp по SEE).

## Как бот ведёт себя за доской

### Дебют

Бот знает **38 дебютных линий** — Испанская, Сицилианская, Итальянская, Французская, Каро-Канн, Ферзевый гамбит, Индийские, Лондонская и другие. В начале партии играет по ним быстро (200–600мс), как человек который помнит теорию.

После 6-го хода есть **15% шанс** «забыть» теорию и переключиться на движок.

Когда выходит из книги — пишет название дебюта в лог:
```
[дебют] Итальянская партия
```

---

### Время на ход

#### Пуля (< 3 мин)

- Дебют (ходы 1–10): 250–700мс
- Быстрые ходы (серия 18% шанс): 80–250мс
- Обычный ход: 0.8–2.3% от времени на часах, макс 2с
- При 40с: 320–920мс · При 15с: 120–350мс

#### Блиц (3–10 мин)

- Дебют: 600–1800мс
- Быстрые ходы: 200–600мс
- Обычный ход: 1–3.5% от остатка, максимум 15с

#### Рапид (10+ мин)

- Дебют: 800–2800мс
- Быстрые ходы: 300–900мс
- Обычный ход: 1.5–4.5% от остатка, максимум 25с

#### Простой эндшпиль (≤ 8 фигур на доске)

Задержка 300–1000мс вместо стандартной, глубина SF максимум 4 — быстро и без лишних раздумий.

#### Цейтнот (любой режим)

| Время | Пауза |
|---|---|
| 6–10 сек | 130–300мс |
| < 6 сек | 20–40мс — мгновенно (турбо) |
| < 3 сек | паника-режим: мгновенный ход Maia или SF d1 |

#### Гипер-турбо (король + 0–1 фигура)

Голый король или король с одной фигурой — задержка 5–15мс.

---

### Эффективное время (пуля)

Бот читает оба часа. Если отстаёшь по времени:

```
effSecs = наше_время − (отставание × 0.5)
```

Пример: у тебя 20с, у соперника 30с → effSecs = 15с → бот играет быстрее.

**Давление на соперника:** если соперник в цейтноте (< 6с) а ты впереди на 4+ сек — полу-турбо 150–400мс.

**Флагование:** отстаёшь на 3+ сек, позиция не выигрышная, < 10с — 8% шанс намеренно затянуть.

---

### Авто-рестарт

Если ход не зарегистрировался на сервере — бот ждёт и перезапускает игровой цикл:

| Ситуация | Таймаут |
|---|---|
| Пуля | 2 секунды |
| Блиц | 4 секунды |
| Рапид | 6 секунд |
| Остаток < 5с | `max(300мс, остаток × 200мс)` — динамически |

В логе: `[авто-рестарт] Ход не прошёл за 2000мс — перезапуск`

---

### Движение мыши

- **Кривые Безье** — плавный разгон и торможение, не прямые линии
- **60% ходов** — наводится на соседнюю клетку, потом на нужную
- **Блуждание во время думы** — мышь медленно ходит по доске пока бот ждёт
- **7% шанс промахнуться** — кликает чуть мимо, потом поправляет
- В турбо — только прямые клики

---

### Премувы (пуля и блиц)

После своего хода бот ставит следующий ход заранее:

1. SF предсказывает лучший ответ соперника
2. SF считает наш ответ на него
3. Кликает оба поля мгновенно — Lichess подсвечивает их синим

Премувы **всегда на Stockfish** (не Maia) — должны быть надёжными.

| Режим | Шанс | Запас времени | Глубина SF |
|---|---|---|---|
| Пуля | 15% | > 8с | 3 |
| Блиц | 10% | > 18с | 5 |

Перед постановкой проверяется:
- у соперника не больше 30 легальных ходов (позиция предсказуема)
- наш ферзь не под ударом после нашего хода
- наша фигура-премув не стоит под взятием

В логе: `[премув SF d3 s20] g1→f3`

---

### Усталость

Каждые 10–15 партий бот входит в режим усталости на 2–3 игры — задержки ×1.3–1.6. Работает в обоих режимах (Combo и чистый SF).

В логе: `[устал]`

### Счётчик партий в день

| Партий | Предупреждение |
|---|---|
| 15 | Рекомендует перерыв |
| 20 | Красный алерт |
