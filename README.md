# Stockfish Chess Bot

Бот для автоматической игры на Lichess и Chess.com. Использует движок Stockfish + Playwright для управления браузером. Имитирует живого человека: задержки, ошибки, дебютная книга, умное флагование.

---

## Быстрый старт

**1. Скачать bot.js**
```
curl -L -o bot.js https://raw.githubusercontent.com/andrikm12345-ux/Stockfish/main/bot/bot.js
```

**2. Установить зависимости** (один раз)
```
npm install chess.js playwright
npx playwright install chromium
```

**3. Положить рядом `stockfish.exe`** (скачать отдельно)

**4. Запустить**
```
node bot.js
```

## Команды в консоли во время игры

| Команда | Пример | Описание |
|---|---|---|
| `d N` | `d 8` | Установить глубину вручную (отключает авто) |
| `s N` | `s 14` | Установить скилл 0–20 (0=слабый, 20=идеальный) |
| `a` | `a` | Включить авто-глубину обратно |
| `r` | `r` | Рестарт игрового цикла — если бот завис и не ходит (браузер остаётся) |
| `p` | `p` | Пауза / продолжить — бот не делает ходы пока на паузе |
| `g URL` | `g https://lichess.org/abc123` | Перейти на игру |
| `n` | `n` | Тупой режим: d1 s1 — ходит как новичок (сохраняет текущие настройки) |
| `b` | `b` | Восстановить настройки, которые были до команды `n` |

## Авто-глубина (работает по умолчанию)

При старте каждой новой игры бот читает часы и сам выставляет глубину:

| Контроль | Время | Глубина |
|---|---|---|
| Пуля | < 3 мин | `depth 5` |
| Блиц | 3–10 мин | `depth 8` |
| Рапид | 10+ мин | `depth 12` |

Команда `d N` отключает авто. Команда `a` включает обратно.

## Скилл — сколько ошибок делает бот

```
s 4–6  → частые зевки, ~70–82% точность — выглядит как слабый игрок
s 7–8  → периодические ошибки, ~80–87% точность — средний игрок
s 9–10 → редкие ошибки, ~83–90% точность — клубный уровень
s 13   → ~88–92% точность — сильный любитель
s 15   → ~91–94% точность — почти мастерской
s 20   → ~98%+ — почти идеально, палевно
```

Поверх скилла работает MultiPV — добавляет ещё ~5–10 cp потерь.

**Рекомендации:**
- Пуля против людей: `s 6–8`
- Блиц против людей: `s 9–11`
- Рапид против людей: `s 12–14`
- Против Stockfish / тренировка: `s 20`

## Как работает бот (логика)

### 1. Дебютная книга
- 37 дебютных линий (Испанская, Сицилианская, Итальянская, Французская, Каро-Канн, Ферзевый гамбит, Индийские, Лондонская, Рети и другие)
- В дебюте ходы играются быстро: 200–600 мс
- После 3-го хода есть **15% шанс** отклониться от книги и играть движком — имитирует человека, который не помнит теорию до конца

### 2. Движок (Stockfish)
- MultiPV = 3 (считает топ-3 хода)
- **20% шанс** сыграть 2-й лучший ход (если разница < 200 очков, только в равной/чуть лучшей позиции)
- **6% шанс** сыграть 3-й лучший ход (только в равной позиции, разница < 120 очков)
- В выигранной позиции (> +200) и проигранной (< -100) — всегда лучший ход

### 3. Задержки — три профиля по типу игры

Бот определяет тип игры автоматически и применяет отдельный профиль задержек.

#### Цейтнот (приоритет во всех режимах)
| Время | Пауза | Клики |
|---|---|---|
| < 6 сек | **Турбо** 20–40мс | мгновенно, без наведения мыши |
| 6–10 сек | 130–300мс | быстро |

#### Пуля (< 3 мин)
| Ситуация | Пауза |
|---|---|
| Дебют (ходы 1–10) | 250–700мс |
| Быстрая серия | 80–250мс |
| Обычный ход | **0.8–2.3%** от эфф. времени, макс 3с |

При 40с остатка: 320–920мс на ход. Иногда думает дольше (×1.5–2.5, 10% шанс).

#### Блиц (3–10 мин)
| Ситуация | Пауза |
|---|---|
| Дебют (ходы 1–10) | 600–1800мс |
| Быстрая серия | 200–600мс |
| Обычный ход | **1–3.5%** от остатка, макс 15с |

При 300с остатка: 3–10с на ход. 12% шанс подумать дольше (×1.2–1.7).

#### Рапид (10+ мин)
| Ситуация | Пауза |
|---|---|
| Дебют (ходы 1–10) | 800–2800мс |
| Быстрая серия | 300–900мс |
| Обычный ход | **1.5–4.5%** от остатка, макс 25с |

При 600с остатка: 9–27с на ход. 18% шанс подумать дольше (×1.3–2.0).

#### Быстрые серии ходов
18% шанс в начале любого хода — бот «видит план» и делает 2–5 ходов подряд быстро. Имитирует человека в потоке.

### 4. Эффективное время и умное флагование (только пуля)

Бот читает **оба часа** — своё время и время соперника.

**Эффективное время** — насколько реально поджимает:
```
effSecs = наше_время − половина_отставания
```
Пример: наше 25с, соперник 35с → effSecs = 25 − 5 = 20с → бот играет как при 20с.
Все пороги (цейтнот, турбо) считаются от effSecs, а не от реального времени.

**Режимы давления:**

| Ситуация | Действие |
|---|---|
| effSecs < 6с (отставание или цейтнот) | Полный турбо: 20–40мс |
| Мы впереди, соперник < 6с, delta > 4с | Полу-турбо 150–400мс — давим на их часы |
| Наше < их на 3+ сек, позиция не выигрышная, < 10с | 8% шанс намеренно просрочить |

В блице и рапиде эффективное время = реальному. Дельта не учитывается.

Лог показывает оба часа: `25с (эфф 17с) | opp 38с`

### 5. Движение мыши
- 60% ходов: сначала наводится на соседнюю клетку, потом на нужную
- Координаты наведения всегда в пределах доски (крайние фигуры не кликают за борт)
- В турбо-режиме: наведение отключено, только прямые клики

### 6. Превращение пешки
- При превращении бот кликает на ту же клетку ещё раз
- В турбо-режиме — без задержки (60–120мс)
- В обычном режиме — небольшая пауза (250–400мс) перед кликом

## Режимы подключения браузера

**Авто (по умолчанию):** бот сам запускает Chrome с отдельным профилем.

**CDP режим** (твой собственный Chrome):
1. Запусти Chrome с флагом:
```
"C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222
```
2. Запусти бота:
```
CDP=1 node bot.js
```
